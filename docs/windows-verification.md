# Windows 实机验证步骤

本仓库的单元测试覆盖拼音残留识别、各家分词符规范化、组字串/按键序列和快捷键解析。这些测试在 Linux 与 Windows CI 上都可以跑。

**下面的项目尚未在真实 Windows 输入法上验证**（开发环境是 Linux，没有中文 IME，也不能操作本机以外的 Windows 桌面）。请在 Windows 10/11 电脑上按本节检查，不要把“单元测试通过”或“CI 编出了 exe”理解成功能已在真机上可用。

建议机器：日常使用的电脑（例如 MSI-Titan16AI）。每个输入法、每个宿主都要单独记结果。

## 1. 安装

1. 从 GitHub Release 下载 `ImeComposeRestore-win-x64.zip`，解压。
2. 双击 `ImeComposeRestore.exe`（不需要安装程序，也不需要管理员权限）。
3. 确认任务栏托盘出现图标（可能收在 `^` 里）。首次运行会在 `%AppData%\ImeComposeRestore\` 写下 `config.json`。
4. 若提示快捷键注册失败，先结束可能冲突的软件，或编辑 `config.json` 的 `hotkey` 后重启程序。

不要用管理员身份运行本程序去“恢复”普通权限窗口里的输入（UIPI 会挡住模拟按键）；反过来，若目标程序本身以管理员运行，则本程序也需要以管理员运行。

## 2. 默认快捷键

- 默认：`Ctrl+Alt+R`
- 可在 `%AppData%\ImeComposeRestore\config.json` 修改 `hotkey`，例如 `"Ctrl+Alt+P"`。不要使用 `Ctrl+Space`、`Win+Space`、`Ctrl+.`、`Ctrl+\``、`F4` 等常见输入法快捷键（程序会拒绝保存这类组合）。
- 改完配置后请退出托盘图标再重新打开程序。

## 3. 基本复现与恢复（每个输入法都做一遍）

准备：记事本（Windows 11 记事本已换引擎，**请同时试「记事本」和「写字板」或旧版记事本**）、以及你日常会打字的软件（VS Code、浏览器地址栏/输入框、Word、微信等）。

对每个组合重复：

1. 切换到该输入法，确认是中文模式（不是英文直出）。
2. 在输入框打一串**不要上屏**的拼音，至少覆盖下面几组：
   - 连续全拼：`woyaokaishi`（不要空格、不要选字）
   - 带单引号分词：`xi'an`、`ni'hao`
   - 若该输入法支持空格分词：`xi an`（注意不要按到“确认候选”的空格）
   - 若微软拼音可带调：`xi1an`
   - 汉字已出一部分、后面还剩拼音：先打出“你好”再继续 `ma`（不要上屏）
3. 在组字未完成时，用 **Alt+Tab** 切到另一个窗口，再切回来（也试一次用鼠标点另一个窗口）。观察并记录：
   - 选字框是否消失；
   - 输入框里留下的**精确字符**（是否有 `'`、空格、弯引号、下划线预编辑）；
   - 此时按空格会出字、上屏字母，还是没反应。
4. 把光标放在残留串末尾（或选中残留串），按 `Ctrl+Alt+R`。
5. 记录：
   - 残留是否被删掉；
   - 候选框是否重新出现；
   - 候选是否与原来那串拼音对应；
   - 托盘通知内容；
   - `%AppData%\ImeComposeRestore\restore.log` 里该次的 `method=`（`ImmSetCompositionString` 还是 `KeySimulation` 还是 `ExistingCompositionRefresh`）。

建议记录表：

| 输入法 | 宿主 | 失焦方式 | 残留串（逐字抄） | 恢复是否成功 | method | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 微软拼音 | 记事本 | Alt+Tab | | | | |
| 微软拼音 | VS Code | 鼠标点走 | | | | |
| 搜狗 | | | | | | |
| 微信输入法 | | | | | | |
| 豆包 | | | | | | |
| 讯飞 | | | | | | |
| 小狼毫 | | | | | | |

小狼毫请特别注意：按源码，失焦时往往会**清空**组字，输入框里可能什么都不剩。这时工具提示“没有识别到残留拼音”是预期行为，不算失败。若看到带下划线的字母但候选没了，把这一条单独记下。

## 4. 负面与边界

- 光标在普通中文或英文句子末尾、没有残留拼音时按快捷键，应提示未识别，且**不得删字**。
- 输入法处于英文模式时，模拟按键可能会再次打出字母；记录这一现象。恢复前请切回中文。
- Chrome / Electron / 游戏全屏 / 密码框 / 远程桌面：重点看能否读到文本。读不到应失败提示，而不是乱删。
- 在资源管理器重命名、任务管理器等短编辑框里试一次。

## 5. 怎样才算“真实可用”

至少同时满足：

1. 在「记事本或写字板」+ 你的主力输入法下，`xi'an` 或 `ni'hao` 这类带分词符的残留，快捷键能重新弹出候选，并且候选与该拼音相符；
2. 删除步骤没有把残留之外的正文吃掉；
3. 连续恢复两次不会把拼音打成双份。

若只有模拟按键能用、IMM `SCS_SETSTR` 无效，仍可视为该输入法上可用，但应在记录里写明走的是按键回退路径，以及英文模式、空格分词等限制。

把填写后的表格和 `restore.log` 片段交给后续维护者，即可据此调整识别规则或默认策略。
